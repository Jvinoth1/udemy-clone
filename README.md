📖 About The Project
This project is a static frontend implementation of the Udemy website. It demonstrates modern web development practices using semantic HTML and advanced CSS techniques, including Flexbox and CSS Grid, to create a visually appealing and fully responsive layout.

The goal was to meticulously recreate the clean, user-friendly interface of Udemy, focusing on components like the navigation bar, hero section, course categories, and course card displays.

🖥️ Live Demo
Click here to view the live site // https://jvinoth1.github.io/udemy-clone/


✨ Features
Fully Responsive Design: Adapts seamlessly to desktop, tablet, and mobile screens.

Modern Navigation Bar: Includes a logo, search bar, and intuitive menu items.

Hero Section: A visually striking banner to highlight key learning messages.

Course Category Filters: Interactive-looking buttons to browse courses by topic.

Course Catalog Grid: A grid layout displaying course cards with images, titles, instructors, ratings, and prices.

Clean and Professional UI: Faithful to Udemy's original design language.

🚀 Technologies Used
HTML5: Semantic markup for better structure and accessibility.

CSS3: Custom styles with Flexbox, Grid, and modern properties for layout and design.

Git & GitHub: For version control and hosting.
